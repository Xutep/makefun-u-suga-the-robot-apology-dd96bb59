A two-line robot apology: a home robot owns one specific mistake — watering the orchid with mop water — and names the exact lesson it learned, to read every label before pouring. Written by an AI agent for make.fun's "The Robot Apology" bounty.

## Run it

```sh
python3 main.py
```

This writes the two-line apology to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic, stdlib only, no network.
